Rxjs Operators

map operator: It will work similar to javascript map operator. It works on observable

filter operator: It will work similar to javascript filter operator. It works on observable

of operator: It will make an observable from a string, array or object.

Take operator: It will emit first count values emitted by the source observable

From operator: It will create an observable from an array, an array-like object. It will always take Array or Array like. It should be iterable. It will not accept single argument like number.
Ex: students2: observable=from(['one','two','three','four'])

From event operator: It creates an observable that emits events of a specific type coming from the given target

Interval operator: It creates an observable that emits sequential numbers every specified interval of time,

First Operator: It will give the first value emitted by the source observable

Pluck Operator : It is deprecated in this angular version
