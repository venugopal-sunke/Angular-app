Guards in Angular

  • CanActivate: Checks to see if a user can visit a route. Implemented CanActivate guard in app-routing.module.ts
  • CanActivateChild: Checks to see if a user can visit a routes children. Implemented CanActivateChild guard in app-routing.module.ts
  • CanDeactivate: Checks to see if a user can exit a route. Implemented CanDeactivate guard in app-routing.module.ts
  • Resolve: Performs route data retrieval before route activation. Implemented Resolve guard in app-routing.module.ts
  • CanLoad: Checks to see if a user can route to a module that is lazy loaded.
