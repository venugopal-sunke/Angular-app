NgRx is a state management library for Angular.

Store: Store contains application data, which is updated through actions and reducers.

Action: An action is an object dispatched to the Store using the dispatch() method. It contains a type and optional payload.

Dispatch: Dispatch takes an action as an argument.We pass information inside the action (payload / properties)
          Dispatch is usually called at the component level. The dispatched action is passed to the reducer function.
		  
Reducer: A reducer is a pure function that takes the previous state and an action as arguments, and returns a new state. 
         It does not modify the state directly. Reducers are called by NgRx automatically when an action is dispatched.
		 
Effects: Effects listen for actions and handle side effects like API calls or logging. They are used for asynchronous operations. 
         After completing their work, Effects can dispatch new actions, which are then processed by reducers to update the store.
		 
Selector: A selector is a pure function that retrieves a specific slice of data from the Store. Components use selectors to 
          read state reactively.
