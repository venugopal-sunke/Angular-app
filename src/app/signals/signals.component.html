Signals in Angular

We can use signals for simple parent to child component communication.

Signal:Signal is a way to store a value that Angular can track reactively. When that value changes, Angular knows which parts of your application depend on it and can update them automatically.


Writable Signal:Stores a value that you can change using set() or update().


Effect:When you create an effect() inside a constructor, you do not need to call it manually. Angular runs it automatically. It runs initially and reruns when its tracked signal dependencies change.


Computed Signal:A computed signal is a signal whose value is calculated from other signals.
